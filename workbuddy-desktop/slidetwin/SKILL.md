# SlideTwin：图片重建为可编辑 PowerPoint

根据用户上传的单页参考图片，调用已连接的 `slidetwin-tools` MCP 工具，在 Windows 桌面版 PowerPoint 中生成一页高保真、可编辑的 PPTX。

用户补充要求：

$ARGUMENTS

## 使用前检查

1. 必须能够访问用户上传的 PNG 或 JPEG 文件，并取得其绝对本地路径。
2. 首先调用 `ppt_environment_status`。
3. 若当前电脑尚未验证 PowerPoint COM，则调用 `ppt_probe_powerpoint`。
4. 若 MCP 不可用或环境检查失败，停止构建并明确报告缺失项，不要假装已生成 PPTX。

## 对象分类原则

将画面中的每个可见对象归入以下类别：

1. **原生 PowerPoint 文字**：普通标题、正文、标签、数字和说明文字。
2. **原生 PowerPoint 图形或连线**：矩形、圆形、卡片、色块、直线、箭头和简单几何图形。
3. **可编辑 SVG 对象**：适合矢量化、但不便用单一 PowerPoint 图形表达的简单装饰。
4. **受保护的独立图片**：照片、复杂插画、艺术字、纹理和细节密集区域。

不得为了提高相似度而把整页参考图作为一张全页背景图片。复杂图像可以保留，但必须作为单独、可移动的图片对象。

## 必须执行的工作流

1. 读取参考图的像素尺寸和长宽比，确认目标幻灯片尺寸。
2. 逐区域分析参考图，完整转录可读文字。
3. 依据 `references/scene-plan-format.md` 写出 UTF-8 编码的 `scene-plan.json`。
4. 对所有对象设置唯一 `id`、合理的 `z` 层级和像素坐标。
5. 调用 `ppt_prepare_image_scene`，检查场景方案并裁切受保护图片。
6. 调用 `ppt_build_editable_slide`，生成可编辑 PPTX 和 PowerPoint 原生渲染图。
7. 调用 `ppt_compare_slide`，生成相似度、叠加图和差异热图。
8. 检查差异最大的区域。仅在差异能够明确修正时，写出 correction plan 并调用 `ppt_apply_correction_plan`。
9. 再次调用 `ppt_compare_slide`。最多执行三轮校正；达到质量目标或改进停滞时停止。
10. 返回最终 PPTX 路径、渲染图路径、比较报告、可编辑对象覆盖情况和仍存限制。

## 质量目标

- 在参考图清晰、字体可用的情况下，目标像素相似度不低于 90%。
- 视觉相似度与可编辑程度必须分别报告。
- 未经比较报告确认，不得声称达到 90%。
- 优先保持对象可编辑，不以整页扁平化换取虚假的高相似度。

## 文件安全

- 不修改用户原文件。
- 每一轮构建和校正写入新的输出目录。
- 不覆盖已有 PPTX。
- 未经用户明确要求，不改变受保护图片的分类和内容。
