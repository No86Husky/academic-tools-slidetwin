# SlideTwin for WorkBuddy

This plugin provides a WorkBuddy-compatible interface for SlideTwin.

The original Codex plugin remains unchanged. This directory is a separate integration layer.

## Purpose

Allow WorkBuddy users to use their selected AI model for slide understanding while SlideTwin handles local PowerPoint reconstruction.

## Development status

Preview integration. The next step is to share the existing SlideTwin MCP runtime without modifying the Codex plugin.
